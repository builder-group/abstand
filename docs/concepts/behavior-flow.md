# Flow

> Status: Concept

Flow is a behavior for building momentum gradually. It is an immersive, progressive focus timer: start with a small work block, check focus after each block, then adapt the next step based on the user's state.

The goal is not a fixed 25-minute cycle. The goal is to help the user begin when resistance is high, grow into deeper work, and keep going when they have reached flow.

## How Flow works

1. **Start small:** the first focus block can be short enough that starting feels easy.
2. **Check focus:** after each block, the user rates their state, such as distracted, okay, focused, or flow.
3. **Adapt:** the next block can shorten, stay the same, or lengthen based on the rating.
4. **Protect momentum:** if the user is already in flow, the behavior should not force an unnecessary break.

## Design intent

Flow should feel like guided entry into deep work, not a stopwatch. The experience can be immersive, but the mechanic must stay simple: small starts, honest check-ins, adaptive blocks, and momentum preservation.
