# Focus

> Status: Concept

Focus is a behavior for narrowing the visible workspace to one chosen app. The selected app stays clear, while other apps recede into the background.

The goal is not to block the whole device. The goal is to reduce visual pull from everything except the app the user chose for the Intention.

## How Focus works

1. **Choose the focus app:** the user selects the app that should remain clear.
2. **Start the Intention:** when the Intention runs, the chosen app remains visually dominant.
3. **Fade the rest:** other apps are blurred, dimmed, or otherwise visually de-emphasized.
4. **End cleanly:** when the Intention ends, the desktop returns to normal.

## Design intent

Focus should feel like clearing the desk around one active tool. It is softer than Block: the rest of the system is not necessarily inaccessible, but it should stop competing for attention.
